DefenderAssist NZ

Creator · 2024 · 1 min read

Search tool that finds words and phrases across large directories of .doc files and shows results in context

Overview

A tool for efficiently searching through .doc files within large directory structures, surfacing results as clickable, contextual quotes.

Problem

Finding specific information buried across large collections of Word documents meant opening files one by one — slow, and easy to miss the document you actually needed.

Constraints

  • Needs to search across entire directory structures, not just a single file
  • Results need enough surrounding context to be useful, not just a filename match
  • Must handle large document directories without becoming unusable

Approach

Built a search tool that scans .doc files across a directory, matches words and phrases, and returns each hit as a contextual quote. Clicking a result opens the source document directly, so users can go from search to source in one step.

Key Decisions

Show results as contextual quotes rather than a flat list of filenames

Reasoning:

A filename match tells you almost nothing; showing the surrounding text lets someone judge relevance before opening the document.

Alternatives considered:
  • Filename-only search results

Tech Stack

  • Document Parsing
  • Full-Text Search

Result & Impact

Cuts down the time spent manually opening documents one by one when looking for specific information across a large collection of files.

Learnings

  • Surfacing context around a match matters more than the search itself — it's what makes results actually usable
